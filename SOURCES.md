# School Data Sources

Last reviewed: **2026-08-10**

This project intentionally distinguishes public-directory data from directly verified school information.

## Consistent public data

Multiple public listings identify **هنرستان پسرانه عصر صنعت** in Fardis as a private boys' vocational/technical school and list these programs:

- الکتروتکنیک
- حسابداری
- شبکه و نرم‌افزار رایانه

The fixed telephone number `026-36508764` appears in the Avval listings.

References:

- https://avval.ir/search/مدارس-غیر-انتفاعی-کرج-با-ادرس-وتلفن-در-فردیس
- https://avval.ir/search/فردیس-کرج/مدارس-غیرانتفاعی

## Address discrepancy

Public listings do not agree on the current street address:

- Avval lists: فردیس، خیابان هجدهم جدید، خیابان عالیانی، پلاک 5
- Other directories list the school around بلوار شهدای فردیس / خیابان بیست‌ونهم / بین کانال و فلکه سوم

References:

- https://www.linkedin.com/pulse/مدارس-و-دبیرستانهای-پسرانه-دخترانه-فردیس-سایت-آگهی-سازه-mjgaf
- https://bazarol.ir/ads/kuwyk/هنرستان-فنی-و-حرفه-ای-عصر-صنعت-در-شهر-فردیس

Because these sources conflict, the public website does not present a precise street address as confirmed fact and asks visitors to call before traveling.

## Intentionally omitted until verified

- official email address
- opening hours
- student or teacher counts
- founding year / years of operation
- current principal or staff directory
- university acceptance statistics
- testimonials
- current admissions dates/capacity

If the school provides authoritative current information, update `assets/data/school.json`, this document, the website metadata, and both README files together.
