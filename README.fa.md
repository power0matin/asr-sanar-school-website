## معرفی

این مخزن شامل پروژه وب‌سایت استاتیک **هنرستان پسرانه عصر صنعت** در **فردیس، استان البرز، ایران** است. سایت عمومی فارسی‌محور است و مستندات مخزن به دو زبان فارسی و انگلیسی نگهداری می‌شوند.

نسخه بازطراحی‌شده عمداً از انتشار ادعاهای تأییدنشده خودداری می‌کند. فهرست‌های عمومی، این مجموعه را هنرستان فنی‌وحرفه‌ای پسرانه غیردولتی در فردیس معرفی می‌کنند و سه رشته **شبکه و نرم‌افزار رایانه، حسابداری و الکتروتکنیک** را برای آن ثبت کرده‌اند. شماره ثابت `026-36508764` نیز در منابع عمومی ثبت شده است. از آن‌جا که نشانی خیابانی در منابع یکسان نیست، سایت از کاربران می‌خواهد قبل از مراجعه تلفنی آدرس روز را تأیید کنند. جزئیات در [SOURCES.md](SOURCES.md) آمده است.

## هویت بصری رسمی

نشان استفاده‌شده در سایت همان لوگوی رسمی ارائه‌شده برای هنرستان است و در `assets/images/school-logo-original.png` بدون تغییر نگهداری می‌شود. فایل `school-logo.png` فقط با حذف فضای شفاف اضافه و حفظ نسبت تصویر برای استفاده در رابط آماده شده است. نسخه‌های Favicon، App Icon و Social Preview نیز مستقیماً از همین نشان ساخته شده‌اند و از تصویر یا لوگوی جایگزین استفاده نمی‌کنند.

## قابلیت‌ها

- رابط فارسی و RTL با فونت محلی Vazirmatn
- استفاده از **نشان رسمی هنرستان عصر صنعت** در Header، Hero، Footer، صفحات رشته‌ها، صفحه 404، Favicon و Social Preview
- طراحی واکنش‌گرا برای دسکتاپ، تبلت و موبایل
- حالت روشن/تاریک پایدار با fallback به Theme سیستم
- منوی موبایل دسترس‌پذیر و Focus Stateهای واضح
- FAQ با همگام‌سازی صحیح وضعیت ARIA
- گالری واکنش‌گرا با صفحه‌کلید، Swipe، توقف/ادامه Autoplay و Lightbox دسترس‌پذیر
- صفحات اختصاصی برای هر سه رشته ثبت‌شده
- Canonical URL، Open Graph، Twitter Card، JSON-LD، `robots.txt` و `sitemap.xml`
- پشتیبانی از Reduced Motion
- حذف فرم تماسی که قبلاً بدون ارسال واقعی پیام موفقیت نمایش می‌داد؛ تماس فعلی از شماره ثابت عمومی استفاده می‌کند
- ابزار Portable برای Screenshot و تست مرورگر
- GitHub Actions برای Validation در Push و Pull Request

## فناوری‌های استفاده‌شده

وب‌سایت Production دارای **صفر وابستگی پکیجی در زمان اجرا** است:

- **HTML5** — ساختار معنایی، Metadata و ARIA
- **CSS3** — Grid/Flexbox، متغیرهای CSS، Responsive Design و Reduced Motion
- **JavaScript خالص** — Theme، منو، FAQ، گالری، Lightbox و Scroll Progress

Playwright فقط به‌عنوان **وابستگی توسعه** برای تست مرورگر و تولید Screenshot استفاده می‌شود.

## شروع کار

برای خود وب‌سایت هیچ Build Step لازم نیست.

```bash
git clone https://github.com/power0matin/asr-sanar-school-website.git
cd asr-sanar-school-website
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

### ابزارهای توسعه

برای اجرای Validation، تست مرورگر یا تولید Screenshot، وابستگی‌های توسعه را نصب کنید:

```bash
npm ci
npx playwright install chromium
npm run validate
npm test
```

برای ساخت چهار Screenshot استاندارد هنگامی که سرور محلی روی پورت `4173` اجراست:

```bash
npm run screenshots
```

برای یک URL دیگر:

```bash
BASE_URL=https://example.com npm run screenshots
```

## دسترس‌پذیری و RTL

سایت شامل موارد زیر است:

- `lang="fa"` و `dir="rtl"`
- Skip Link به محتوای اصلی
- Focus State واضح با `:focus-visible`
- همگام‌سازی `aria-expanded` در منوی موبایل
- همگام‌سازی `aria-expanded` در FAQ
- گالری و Lightbox قابل کنترل با صفحه‌کلید
- بازگرداندن Focus و محدودسازی Focus در Lightbox
- پشتیبانی از `prefers-reduced-motion`
- رنگ متن با Contrast مناسب برای WCAG AA روی سطوح اصلی

## SEO و استقرار

Canonical فعلی پروژه GitHub Pages است:

`https://power0matin.github.io/asr-sanar-school-website/`

اگر پروژه به دامنه رسمی منتقل شد، Canonical، Open Graph URL، Sitemap، مقدار `start_url` در Manifest و Structured Data باید هم‌زمان به‌روزرسانی شوند.

سایت را می‌توان روی Netlify، Vercel، Cloudflare Pages یا هر وب‌سرور استاتیک دیگری نیز مستقر کرد.

## تست

`npm run validate` لینک‌های محلی، IDهای تکراری، Metadata ضروری، برگشت Placeholderها، Hookهای دسترس‌پذیری و هماهنگی اطلاعات هنرستان را بررسی می‌کند.

`npm test` یک وب‌سرور محلی اجرا کرده و سایت را با Chromium آزمایش می‌کند، از جمله:

- Horizontal Overflow در دسکتاپ و موبایل
- تغییر و ماندگاری Theme
- عملکرد FAQ و ARIA
- باز و بسته شدن Lightbox و آزاد شدن Scroll صفحه
- وضعیت منوی موبایل
- هر سه صفحه رشته
- خطاهای مدیریت‌نشده JavaScript

CI هر دو بررسی را روی Push به `main` و Pull Request اجرا می‌کند.

## به‌روزرسانی اطلاعات هنرستان

از [`assets/data/school.json`](assets/data/school.json) شروع کنید و سپس متن عمومی و Metadata را همگام کنید. بدون منبع معتبر یا تأیید مستقیم هنرستان، آمار، نشانی، ایمیل، نام کادر، Testimonial یا ادعای ثبت‌نام اضافه نکنید.
